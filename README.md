# Lasso Regression — Key Points

## 📌 Project Overview

This project explains the **core concepts of Lasso Regression (L1 Regularization)** and why it is one of the most popular regularization techniques in Machine Learning.

Using a synthetic dataset generated with Scikit-Learn's `make_regression`, the notebook focuses on understanding how the **L1 penalty** shrinks coefficients and performs **automatic feature selection** by reducing less important feature weights to zero.

---

## 🎯 Objectives

* Understand the fundamentals of Lasso Regression
* Learn how L1 Regularization works
* Explore automatic feature selection
* Study the impact of different alpha (λ) values
* Compare Lasso Regression with Ridge Regression

---

## 📂 Dataset

**Dataset Used:** `make_regression`

A synthetic regression dataset generated using Scikit-Learn to demonstrate the concepts of regularization and feature selection.
